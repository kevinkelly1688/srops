# StarRocks 运维平台（v1.7.5）

可交互的高保真原型：纯前端、零依赖、模拟数据。知识来源为 StarRocks 官方中文文档 <https://docs.mirrorship.cn/zh/docs/>（Latest 4.1 / Stable 3.5）。

## 两种运行方式

| 方式 | 说明 |
|---|---|
| **平台服务（真实）** | 运行 Go 服务端 `backend/` 中的 `sr-ops`，登录后导入真实集群。已接入：集群导入、集群总览、集群架构、性能巡检、查询分析（含 SQL 审计）、资源隔离、导入作业、物化视图、备份恢复、参数配置、告警中心、节点管理、安装部署、升级回滚、用户管理、角色权限、操作审计、平台设置（全部页面）。见 [backend/README.md](backend/README.md) |
| **原型演示** | 直接打开 `index.html` 或用静态服务器访问，全部为模拟数据 |

## 原型演示打开方式

- 直接双击 `index.html`（file:// 即可，手册已打包进 `js/help_content.js`）；或
- `python -m http.server 8766` 后访问 <http://127.0.0.1:8766/>。

打开后先进入**登录页**（仅平台本地账号 + 密码），页面底部的“原型演示账号”下拉框可一键填充；勾选“模拟全新部署”可从空平台体验导入集群流程。界面支持浅色 / 深色 / 🌿护眼三种主题。登录后顶栏右侧仍可**切换登录身份**（admin / ops_zhang / dba_li / oncall_wang / auditor_chen），直观对比不同角色的菜单与按钮权限；顶栏可切换集群（存算一体 / 存算分离）。

## 权限设计

- 菜单权限 `<页面>:view` + 按钮权限 `<模块>.<动作>`；角色 = 权限码集合 + 数据范围；用户多角色取并集。
- 所有按钮统一经 `B(权限码, 文本)` 渲染（`js/perm.js`）：无权限时置灰 + 🔒（可配置为隐藏），悬停提示所需权限码。
- 高危按钮需输入集群名确认，可开启双人复核；所有操作（含被拒绝的尝试）写入审计。
- 权限目录唯一来源：`js/perm.js` 中的 `PERM_TREE`，菜单、角色配置树、权限矩阵、手册附录均由其生成。

## 目录

```
index.html            入口
css/style.css         样式（浅色 / 深色 / 护眼主题）
js/data.js            模拟数据（注释标明对应的 StarRocks SQL / 接口）
js/core.js            工具、图表、弹窗、路由、按钮动作分发、审计
js/perm.js            权限目录、预置角色与用户、can() / B()
js/p_*.js             各页面
js/cluster_import.js  集群导入向导、引导页、全新部署演示
js/login.js           登录页、个人菜单、主题
js/watermark.js       页面水印（仅超级管理员可配置）
js/help_content.js    手册打包（自动生成）
help/*.md             使用手册（唯一来源）
docs/用户使用手册.md   完整手册合订本（自动生成）
tools/build_help.py   生成 permcodes.md、help_content.js、用户使用手册.md，并按 VERSION 给 index.html 资源加版本号
```

修改 `help/*.md` 或 `js/perm.js` 后运行：

```bash
python tools/build_help.py
```

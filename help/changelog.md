# 更新记录

## v1.7.5（2026-10-20）

### 文档

- 常见问题新增「读取审计表失败」的完整处理方法：确认原因（`Unknown database 'starrocks_audit_db__'` 说明集群没装 AuditLoader）、安装 AuditLoader 插件的步骤与 `plugin.conf` 配置项、给平台账号授权；「查询分析」的说明里加了指向该问题的链接。
- 更新记录补充 v1.7.1 – v1.7.4。

## v1.7.4（2026-10-20）

### 变更

- **一键修复的确认弹窗不再要求输入文字**：点「确认修复」即可执行（开启双人复核时按钮为「提交复核」）。其它高危操作（删除主机、删除安装包、执行部署等）的“输入名称确认”不变。

## v1.7.3（2026-10-20）

### 修复

- 一键修复「安装目录可写」时提示“部署目录 "" 不合法”：请求里没有带部署目录（例如升级后浏览器仍在用旧版页面脚本）。现在会沿用该用户最近一次预检的安装目录；没有预检过时给出明确提示。升级时请连同 `web/` 目录一起升级（用 `install.sh upgrade` 即可）。

## v1.7.2（2026-10-20）

### 新增：安装目录一键修复

- 环境预检的「安装目录可写」可以一键修复：用 `sudo mkdir -p` 创建部署目录，并 `sudo chown <SSH 用户>:` 交给部署用的 SSH 用户（需要 root 账号或免密 sudo）。
  - 只处理这一个目录本身，不递归；目录至少两级，不在 `/usr`、`/etc`、`/var` 等系统目录下，也不能是 `/home/<用户>` 本身，否则不提供修复，请手工创建并授权；
  - 目录已存在且属于 root 和 SSH 用户之外的账号时不会改动，避免影响其他服务；
  - 与 JDK 一起修复时，先处理安装目录。

## v1.7.1（2026-10-19）

版本号从 v1.7.1 起重新编号（此前最后一个版本为 v0.10.0）。

### 新增

- **使用期限与 ICP 备案号**：写在安装目录的 `sr-ops.conf` 里，修改后执行 `systemctl restart sr-ops` 生效，升级时保留。
  - `SR_EXPIRE=2028-01-01`：使用期限（含当天），未配置时即为 2028-01-01。到期后平台照常运行，页面不做任何提醒，只在日志里记录；
  - `SR_ICP=...`：ICP 备案号，显示在登录页和主界面底部（链接到工信部备案查询网站），留空则不显示。早期安装的 `sr-ops.conf` 里没有这两项，需要显示备案号时手工加一行。
- **版本号显示**：登录后侧边栏左下角显示平台版本号，随打包生成（来自安装包里的 `VERSION`）；「平台设置 → 基础」里的“平台版本”读取同一个版本号。

## v0.10.0（2026-10-09）

### 新增：自定义 PromQL 告警规则、短信渠道、备份快照清理

- **自定义 PromQL 告警规则**（`alert.rule`）：在「告警中心 → 告警规则」新建任意 PromQL 规则，平台每分钟对配置了 Prometheus 的集群执行一次即时查询，**返回的每条序列是一个告警对象**；比较方式 ≥ / > / ≤ / <、警告 / 严重阈值、持续时间、通知渠道，以及合并、静默、认领、恢复通知与内置规则一致。表达式里的 `$sel` 替换为集群的 Prometheus 选择器；保存前可**在所选集群上试运行**（显示返回的序列和取值，语法错误原样显示 Prometheus 的报错）。Prometheus 查询失败不会把已有告警当作恢复；停用 / 删除规则后其告警立即关闭。最多 50 条。
- **短信渠道**：告警渠道新增“短信”（手机号加密保存、页面脱敏显示）；「平台设置 → 通知 → 短信网关」支持**阿里云短信**、**腾讯云短信**（签名 + 模板，按顺序填写模板变量）和**通用 HTTP 网关**，密钥加密保存，可先**发送测试短信**；渠道的测试按钮真实发送。
- **备份快照清理**（新增权限码 `backup.clean`，高危，可走双人复核）：StarRocks 没有删除快照的 SQL，平台通过 S3 协议（`s3` / `s3a` / `oss` / `cos` / `obs` / `tos`）直接删除对象存储中的快照目录。
  - 「仓库 → 清理设置」配置清理凭据（加密保存，保存前先列出仓库目录验证）；
  - 「快照列表」勾选快照后可**手动删除**；
  - 备份策略新增**保留策略**（保留最近 N 份 / 保留 N 天内，只清理该策略自己创建的快照，最新的一个永远保留）：平台每小时自动清理，每次最多删除 10 个；策略列表可**预览**并**立即清理**；
  - 安全保护：只删除 `__starrocks_repository_<仓库>/__ss_<快照>/` 目录；有进行中的恢复作业时拒绝；同一仓库同时只有一个清理任务；每个快照的删除结果写入审计。
- 假集群 `fakesr` 新增内存 S3 服务（`-s3-port`），备份仓库的快照与对象存储里的文件联动，可演示快照清理。
- **安装包「从服务器导入」**（`deploy.pkg`）：安装包已经在服务器上（如直接 wget 下载）时，放到 `<数据目录>/import/`（或已放进 `packages/` 但未登记）后，在「安装部署 → 安装包」点「从服务器导入」即可校验并登记，不必再经浏览器上传；只接受这两个目录里的文件名，不接受任意路径。
- **一键部署脚本 `install.sh`**（安装包内）：`install` / `upgrade` / `rollback` / `uninstall` / `status`。升级前自动备份程序与数据、拒绝降级、健康检查失败自动回滚；卸载默认保留数据目录，`--purge` 彻底删除；启动参数保存在 `sr-ops.conf`，升级不覆盖；兼容按手册手工安装的旧版本。详见「平台部署与集群导入」。

### 变更

- 「平台设置 → 通知」的短信网关由“仅保存”变为真实生效；告警渠道的“暂不支持短信 / 自定义 PromQL”说明已移除。

### 已知限制

- 快照清理只支持 S3 协议的仓库，HDFS / Azure 等需要在存储上自行清理；对象存储的目录布局（`__starrocks_repository_<仓库>/__ss_<快照>/`）依据 StarRocks 当前版本，**首次使用请先在测试仓库验证**（用“预览”和手动删除一个测试快照）。
- 阿里云 / 腾讯云短信只在模拟网关上验证了请求格式与签名流程，首次使用请先用「发送测试短信」确认；短信模板变量每个最多 20 个字。
- 自定义规则只支持即时向量查询，不支持告警规则分组、模板化通知内容与自定义标签。

## v0.9.0（2026-10-09）

### 新增：需要 SSH 的三个页面（服务端）——至此全部页面都是真实功能

- **节点管理（真实）**：启动 / 停止 / 重启通过 SSH 执行安装目录下的脚本，在服务端后台任务里执行并保存日志；BE / CN（3.4 及以上）默认优雅退出（`-g`）；停止 / 重启 FE 前检查存活的 Leader + Follower 是否仍占多数；重启会等待节点重新存活。下线（DECOMMISSION）、移除（DROP）、黑名单（带原因，StarRocks 不保存原因，由平台记录）走 SQL；节点日志通过 SSH 读取（文件白名单、关键字过滤）；新增“操作记录”页签。
- **节点扩容（真实）**：在已纳管主机上安装与集群同版本的 FE / BE / CN 并加入集群——上传安装包并校验 SHA256、沿用集群里同类型节点的配置、按官方顺序 `ADD`（FE 先 ADD 再 `--helper` 启动，BE / CN 先启动再 ADD）；开始前预检，并验证新主机能用集群的 SSH 配置登录。
- **安装部署（真实）**：
  - 主机管理：批量添加（支持末段范围）、首次用密码把平台公钥写入 `authorized_keys` 之后一律用密钥（密码不保存）、自动探测规格；
  - 安装包：流式上传（最大 8 GB）、边写边校验压缩包内容与 SHA256；
  - 环境预检（15 项，只读）与**一键修复**（sysctl、swap、THP、limits、JDK 安装）；
  - 部署向导：从零部署存算一体 / 存算分离集群（启动 Leader FE → 设置 root 密码 → 其余 FE → BE / CN → 校验 → 自动接入平台）；日志实时可见，失败后可**重试**（已完成的步骤会跳过）、执行中可取消。
- **升级回滚（真实）**：升级计划（路径校验：不能跨小版本、不能降级）、升级前检查（12 项）、**滚动升级**（BE → CN → FE，逐台：优雅停止 → 备份旧 `bin / lib`（FE 还备份元数据）→ 换新版本 → 启动 → 等待以新版本存活 → 等待 Tablet 健康）、暂停 / 继续 / 取消、中断后继续（已升级的节点跳过）、**回滚**（FE → CN → BE，把备份目录换回；备份丢失时用旧版本安装包兜底）。
- **参数配置：持久化到配置文件（真实）**：修改弹窗里可勾选“同时写入配置文件”，通过 SSH 修改各节点的 `fe.conf` / `be.conf` / `cn.conf`（先备份、原地替换、原子写入），需要权限码 `param.persist`；静态参数可以只写配置文件，重启节点后生效。

### 变更

- 新增后台任务机制：节点启停、扩容、部署、升级都是服务端后台任务，日志保存在 `data/tasks/`，平台重启后可查看；重启时仍在执行的任务标记为失败，部署 / 升级可继续。
- 高危操作接入服务端双人复核：停止 / 重启 / 下线 / 移除节点、一键修复、执行部署、执行升级、回滚。
- 假集群 `fakesr` 新增 `-hosts` 模式：每个节点独立地址、独立的 SSH 主机（虚拟文件系统、内核参数、进程、日志），可以演示部署、扩容、升级。

### 已知限制

- 平台只在升级时替换 `bin`、`lib`（FE 还有 `spark-dpp`），不改 `conf/`；新版本新增的配置项需要自行添加。升级产生的 `*.bak-<版本>` 备份目录与上传到主机的安装包不会自动清理。
- 同一台主机上同类型节点只支持一个（节点操作按“主机 + 部署目录”定位）。
- 部署使用官方默认端口，暂不支持自定义端口；部署的所有主机须使用同一组 SSH 用户与端口。
- 本版本在模拟环境中完成测试；对真实集群的 SSH 操作（尤其是升级与回滚）请先在测试集群验证。

## v0.8.0（2026-10-09）

### 新增：告警中心（服务端）

- **告警由平台评估**：每分钟读取各集群的总览数据评估 9 条内置规则（集群连接失败、节点失联、BE 磁盘、Compaction Score、FE JVM、查询 P99、Routine Load 暂停、物化视图刷新失败、不健康 Tablet），不依赖 Prometheus。支持“持续时间”、警告 / 严重两级阈值、自动恢复；采集失败不会把告警误判为恢复。
- **当前告警 / 历史**：认领（认领后不再重复提醒）、静默按钮自动带入集群 / 规则 / 对象；侧栏角标与总览“活跃告警”卡片改为真实告警；数据范围受限的用户只看到范围内的告警。
- **告警规则**：可调阈值、持续时间、通知渠道、启停，可恢复默认（全局生效，需要“全部集群”数据范围）。
- **静默**：按集群 / 规则 / 对象文本匹配，5 分钟到 30 天，到期自动失效。
- **通知渠道（真实发送）**：企业微信、钉钉、飞书、Lark、Slack、通用 Webhook、邮件；地址与密钥加密保存；按级别过滤；测试按钮；显示最近发送结果。
- **发送策略生效**：告警合并、重复提醒、恢复通知、免打扰时段（严重级别照常发送）；发送失败 5 分钟后重试；通知结果写入审计。

### 变更

- 「平台设置 → 通知」的发送策略不再是“仅保存”，现已对告警中心生效。
- 移除集群时一并清理该集群的告警与静默。

### 已知限制

- 暂不支持自定义 PromQL 规则、短信渠道与自定义消息模板。

## v0.7.0（2026-10-09）

### 新增：直接通过 SQL 管理集群的六个页面（服务端）

- **资源隔离（真实）**：资源组的查看、新建、编辑、删除（含分类器的增删，修改时先加后删，不留“无分类器”的空档）；显示每个资源组正在运行 / 排队的查询数；查询队列配置自动区分全局变量与 FE 配置，FE 配置在每个存活 FE 上逐台修改。
- **导入作业（真实）**：Routine Load 列表、暂停 / 恢复 / 停止、详情（暂停原因、消费进度、错误数据地址、当前子任务）；最近的 Broker Load / Stream Load / Insert 记录与失败比例。
- **物化视图（真实）**：列表、刷新（全部分区 / 指定分区区间 / FORCE）、启用 / 停用、取消刷新、查看定义；刷新进行中自动刷新页面。
- **查询分析（真实）**：运行中查询（全部 FE 汇总，可自动刷新）、终止查询（终止前重新核对 Query ID 与连接）、Query Profile 与 ANALYZE PROFILE、执行计划分析（EXPLAIN / EXPLAIN COSTS，只接受单条 SELECT / WITH）、慢查询 Top SQL（按 SQL 指纹聚合审计表，可筛选，可导出 CSV）、SQL 黑名单（过宽的规则会被拒绝）。
- **SQL 审计（真实）**：「操作审计」的 SQL 审计页签读取集群审计表，可按时间、用户、库、状态、耗时、关键字筛选并分页。
- **备份恢复（真实）**：仓库（S3 / 兼容 S3 / HDFS，访问密钥不保存、审计中脱敏）、快照列表、发起备份、恢复（快照与时间戳从仓库列表选择）、取消、作业进度；**备份策略由平台定时执行**（每天 / 每周，跳过已有进行中作业的库，结果写入审计）。
- **参数配置（真实）**：FE 配置、BE / CN 配置、全局变量的查看与在线修改（FE、BE 逐台执行），节点参数对比（只列不一致的参数），变更历史。

### 变更

- 所有新增的高危操作（删除资源组、停止 Routine Load、终止查询、增删黑名单规则、恢复数据、修改参数）接入服务端双人复核。
- 双人复核的申请标题现在可以包含请求内容（如“修改参数 qe_slow_log_ms = 4000”）。
- 假集群 `fakesr` 支持上述操作并保存状态，便于联调与测试。

### 已知限制

- 参数的“持久化到配置文件”、节点管理、安装部署、升级回滚需要 SSH，将在后续版本提供；FE / BE 参数的在线修改仅内存生效。
- StarRocks 没有删除快照的 SQL 命令，备份策略不清理旧快照。
- 物化视图暂不显示“查询改写命中次数”；导入作业暂不管理 Pipe。

## v0.6.0（2026-10-09）

### 新增：操作审计与平台设置（服务端）

- **操作审计（真实）**：读取服务端审计日志，按账号、结果、起止日期、关键字筛选，分页加载；显示菜单、权限码与变更明细（角色权限增减、设置项“旧值 → 新值”）；**导出 CSV**（最多 5 万条，防公式注入，导出本身也记录）；范围受限的用户只能看到范围内集群的记录和自己的操作；超过保留期（默认 180 天，不少于 180 天）的记录自动清理。
- **双人复核（服务端强制）**：开启后，移除集群、删除用户、删除角色等高危操作先进入「待复核」；另一位拥有同权限且数据范围包含该集群的用户批准后，平台以提交人的身份执行，并重新校验提交人的账号与权限；支持驳回、撤回，24 小时自动失效；提交人不能复核自己的申请。
- **平台设置（真实）**：
  - 安全策略：会话超时、密码最小长度与过期天数、登录失败锁定次数、IP 白名单（含防自锁、本机始终放行、可信代理 `-trusted-proxies`）、高危操作二次确认、无权限按钮显示方式全部保存在服务端并生效。
  - 通知：邮件服务（SMTP，SSL / STARTTLS / 不加密，密码加密保存）可**真实发送测试邮件**；短信网关与告警发送策略已保存，告警中心接入后生效。
  - 基础：平台名称、访问地址、出网代理（用于 Lark / Slack 等，密码隐藏）、采集间隔、巡检报告与审计日志保留期。
  - 水印：保存到服务端，仅超级管理员可改，所有用户生效；`{ip}` 变量显示真实来源 IP。
- **邮件通知**：定时巡检结果通知新增「邮件」方式；创建 / 重置用户时可选“同时发送账号与密码到用户邮箱”。
- 通知消息带“查看详情”链接（配置了平台访问地址时）。

### 变更

- 无权限（越权）请求的审计结果归类为“拒绝”，不再算作“失败”。
- 启动参数新增 `-trusted-proxies`。

## v0.5.0（2026-10-09）

### 新增：用户管理与角色权限（服务端）

- **权限由服务端校验**：每个接口按权限码校验，用户的权限 = 所有角色的并集，数据范围（集群）同样在服务端过滤。角色或用户变更对已登录用户立即生效；锁定、删除、重置密码使其会话立即下线。
- **用户管理（真实）**：新建 / 编辑 / 重置密码 / 锁定 / 删除，支持部门、手机、有效期；初始密码可手动指定或随机生成（仅显示一次）；列表显示锁定、登录失败锁定、已过期、待改密等状态。
- **角色权限（真实）**：新建 / 复制 / 改名 / 编辑权限（精确到按钮）/ 数据范围 / 删除；首次部署写入预置角色（运维管理员、DBA、值班只读、审计员）；权限树与前端共用同一份定义，保存时校验“按钮权限必须同时拥有所属菜单的查看权限”。
- **防越权提升**：只能授予、管理权限与数据范围不超过自己的角色与用户；不能修改自己的角色；至少保留一个可用的超级管理员；内置账号 admin 不可锁定 / 删除。越权尝试写入审计。
- 连接平台服务时，「用户管理」「角色权限」为真实数据；按当前用户的权限显示菜单、按钮和集群。详见 [用户、角色与权限](#help/permission)。

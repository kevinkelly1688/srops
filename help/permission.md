# 用户、角色与权限

## 1. 权限模型

```
用户 ──(多个)──> 角色 ──> 功能权限：菜单「查看」+ 按钮权限码
                      └─> 数据范围：可访问的集群
```

- **菜单权限** `<页面>:view`：决定左侧菜单是否显示、页面能否打开。直接访问无权限的页面会显示 403。
- **按钮权限** `<模块>.<动作>`：平台上每个操作按钮都有唯一权限码，例如 `node.decommission`、`backup.restore`。完整清单见 [权限码清单](#help/permcodes)。
- **数据范围**：角色可访问的集群；“全部集群”包含以后新导入的集群。
- 用户拥有多个角色时，功能权限与数据范围均取**并集**。
- **高危**按钮（清单中标 ●）执行前需输入集群名确认，可配置双人复核。

## 2. 预置角色

| 角色 | 内置 | 定位 | 数据范围 |
|---|---|---|---|
| 超级管理员 | 是 | 全部功能，含用户与权限管理，不可修改 | 全部 |
| 运维管理员 | 否 | 集群全部运维操作，不能管理用户与角色 | 全部 |
| DBA | 否 | 查询、资源组、参数、导入、物化视图、备份；节点只读 | 首次部署时为空，由管理员指定集群 |
| 值班只读 | 否 | 监控、巡检、告警查看，可认领告警 | 全部 |
| 审计员 | 是 | 只读审计日志与用户 / 角色配置 | 全部 |

## 3. 用户管理

「平台配置 → 用户管理」：

| 按钮 | 权限码 | 说明 |
|---|---|---|
| ＋ 新建用户 | `user.create` | 账号、姓名、部门、邮箱、手机、初始密码、角色、有效期 |
| 编辑 | `user.edit` | 修改信息与角色；变更立即生效 |
| 重置密码 | `user.reset` | 生成随机密码（或手动设置），**仅显示一次**；该用户所有会话立即下线，并解除登录失败锁定；首次登录强制修改 |
| 锁定 / 解锁 | `user.lock` | 锁定后无法登录，**离职人员推荐锁定而不是删除** |
| 删除（高危） | `user.delete` | 历史审计保留 |

规则：内置账号 `admin` 不可锁定 / 删除，且必须保留超级管理员角色；不能锁定、删除或重置当前登录账号；至少保留一个可用的超级管理员。

### 用户字段与状态

| 字段 | 说明 |
|---|---|
| 账号 | 3–32 位字母、数字、下划线，不区分大小写，创建后不能修改 |
| 姓名 / 邮箱 | 必填 |
| 部门 / 手机 | 选填；手机后四位可用于水印 |
| 初始密码 | 留空则由平台生成随机密码，创建成功后**仅显示一次**；也可手动指定（须符合密码策略：至少 10 位，含大小写字母、数字和符号）。用户首次登录必须修改 |
| 有效期 | 选填日期；到期当天结束后不能登录，已登录的会话立即失效。留空 = 永久 |

用户状态：**正常**；**已锁定**（管理员锁定）；**登录失败锁定**（连续输错 5 次密码，30 分钟后自动解除，管理员点「解锁」可立即解除）；**已过期**（超过有效期，编辑用户修改有效期后恢复）；**待改密**（尚未修改初始 / 重置后的密码）。

### 服务端校验与防越权

连接平台服务时，权限由**服务端**在每次请求时按最新角色校验，前端按钮只是展示：

- 角色、用户的任何变更对已登录用户**立即生效**，无需重新登录；锁定、删除、重置密码会让该用户的会话立即下线。
- **只能授予、管理权限不超过自己的角色与用户**：一个角色的权限或数据范围只要超出你自己的，你就不能把它授予别人、也不能编辑它或拥有它的用户（页面上显示 🔒 / “无权管理”）。因此拥有「用户管理」权限的人无法给自己或他人提权成超级管理员。
- 不能修改自己的角色与有效期；改自己的资料、修改密码不受限制。
- 数据范围受限的用户，接口只返回其可访问的集群；访问范围外的集群一律拒绝。导入集群、修改巡检规则阈值（对所有集群生效）需要“全部集群”数据范围。
- 所有用户 / 角色变更与被拒绝的越权尝试都会写入操作审计；密码不会出现在审计或日志中。

## 4. 角色权限配置（精确到按钮）

「平台配置 → 角色权限」左侧为角色列表，右侧有三个页签。

### 功能权限

以“分组 → 菜单 → 按钮”的树形展示全部权限：

1. 勾选菜单名前的复选框 = 授予该菜单 **查看** 权限。
2. 勾选按钮 = 授予该按钮权限；**勾选任意按钮会自动勾选所属菜单的查看权限**。
3. 取消菜单查看 = 同时取消该菜单下所有按钮。
4. 分组标题的复选框可整组全选 / 清空；右上角提供 **全选 / 清空 / 仅查看** 快捷操作。
5. 每个按钮旁显示权限码，红点 ● 表示高危。

修改后底部提示“有未保存的修改”，点击 **保存**（`role.edit`）会弹出**变更对比**（新增哪些、移除哪些、数据范围），确认后立即对该角色全部成员生效，并记录审计。**撤销** 恢复到上次保存的状态。

### 数据范围

勾选该角色可访问的集群，或勾选“全部集群”。

### 成员

查看拥有该角色的用户。分配角色请在「用户管理 → 编辑用户」中进行。只有「角色权限」查看权限、没有「用户管理」查看权限的用户，看不到成员的邮箱和手机。

### 其他操作

| 操作 | 权限码 |
|---|---|
| 新建角色（可从已有角色复制初始权限） | `role.create` |
| 复制角色 | `role.copy` |
| 改名 / 描述 | `role.edit` |
| 删除角色（有成员时不允许删除；内置角色不可删除） | `role.delete` |
| 查看全部角色权限矩阵（可打印） | 有本页查看权限即可 |

### 内置角色

- **超级管理员**：固定拥有全部权限与全部集群，不可修改、删除；用户列表中只有它的成员可以管理其他超级管理员。
- **审计员**：内置，不可改名、删除，但权限与数据范围可以调整。
- 其余预置角色可以修改、删除。移除某个集群时，它会自动从所有角色的数据范围中去掉。

## 5. 配置示例：为“只做巡检和查询优化”的 DBA 建角色

1. **新建角色**，名称“查询优化 DBA”，初始权限选“空白”。
2. 在功能权限中勾选：
   - 集群总览（查看）、集群架构（查看 + 查看节点详情）
   - 性能巡检：立即巡检、导出巡检报告
   - 查询分析：查看 Query Profile、执行计划分析、导出慢查询（**不勾**“终止查询”）
   - 资源隔离：查看
3. 数据范围勾选 `prod-sr-01`。
4. 保存，在用户管理中把该角色分配给对应人员。
5. 用顶栏“切换用户”（原型）或让该同事登录，确认菜单与按钮符合预期。

## 6. 最小权限建议

- 生产环境的高危按钮（停止 / 下线 / 恢复 / 删除类）只授予少数运维管理员，并开启双人复核。
- 值班人员只读 + 告警认领。
- 审计员独立角色，不授予任何运维操作。
- 页面水印只能由「超级管理员」修改，不能通过角色授权给其他人；超级管理员角色应只授予极少数人。
- 定期在角色权限矩阵中复核权限，离职人员及时锁定。

# 参数配置

分 **FE 配置**、**BE / CN 配置**（存算分离为 CN 配置）、**全局变量**、**变更历史** 四个页签。支持搜索参数名；全局变量可“只看已修改”，BE / CN 可“只看节点间不一致”。

## 1. 参数类型与生效方式

| 类型 | 数据来源 | 修改方式 | 持久化 |
|---|---|---|---|
| FE 配置 | `ADMIN SHOW FRONTEND CONFIG` | `ADMIN SET FRONTEND CONFIG ("k" = "v")`，平台在**每个存活的 FE** 上逐台执行 | 默认仅内存生效，FE 重启后恢复；勾选「同时写入配置文件」后写入 `fe.conf` |
| BE / CN 配置 | `information_schema.be_configs` | 对每个节点调用 HTTP `POST /api/update_config?k=v` | 默认仅内存生效，节点重启后恢复；勾选后写入 `be.conf` / `cn.conf` |
| 全局变量 | `SHOW GLOBAL VARIABLES` | `SET GLOBAL k = v` | 自动持久化，对新会话生效 |
| 静态参数（标“需重启”） | — | 不能在线修改 | 用 **写入配置文件** 只改配置文件，重启节点后生效 |

> 变量里的“已修改”标记来自 StarRocks 返回的默认值（部分版本不返回默认值，则不显示）。

## 2. 修改参数

1. 在列表中找到参数，点击 **修改**（`param.edit`，高危，可走双人复核）。静态参数没有修改按钮。
2. 填写新值。FE / BE 参数的作用范围是**全部节点**（统一改成同一个值）。
3. 确认生成的命令，输入集群名后执行。
4. 某些节点修改失败时，页面会列出失败的节点和原因，并提示已成功的节点；这次修改仍会记入变更历史（状态为“失败”）。

> 如果该参数在各节点上的取值本来就不一致，修改后会**统一为新值**；页面会在修改前提示。

## 3. 持久化到配置文件

需要权限 **`param.persist`**（持久化到配置文件）和集群的 SSH 信息与部署目录。在「修改参数」弹窗里勾选 **同时写入配置文件**：

1. 先在线修改（和不勾选时一样）；成功后再写配置文件。在线修改失败则不会写文件。
2. 平台通过 SSH 登录**作用范围内的每台主机**：读取 `<部署目录>/conf/fe.conf`（BE 为 `be.conf`，CN 为 `cn.conf`），先**备份**为 `fe.conf.bak-<时间>`，再把该参数设置为新值：文件里已有该参数（包括 `key=value`、前面有空格的写法）就**原地替换**，保留注释和其他行；没有就追加到末尾。写入用“临时文件 + `mv`”，不会留下写了一半的文件。
3. 作用范围里的某台主机写入失败时，页面报错并列出已经写入的主机；变更历史和审计会记录“部分写入”与失败原因。审计详情里列出每台主机写入的文件和备份文件名。

**静态参数**（标“需重启”，没有「修改」按钮）可以用 **写入配置文件** 按钮：**只修改配置文件，不改在线值**，需要重启对应节点后才生效。

> 不勾选“写入配置文件”时，FE / BE 的在线修改只在内存中生效，节点重启后恢复为配置文件里的值。全局变量用 `SET GLOBAL`，本来就会持久化，不需要写文件。

## 4. 节点参数对比

**节点参数对比**（`param.compare`）读取每个 FE（或每个 BE / CN）的配置，**只列出各节点取值不一致的参数**，与多数节点不一致的值高亮，用于发现“某台节点被单独改过参数”。要把它改一致，在列表中修改该参数即可。

## 5. 变更历史

记录**通过平台**做的每一次修改：时间、操作人、类型、范围、旧值、新值、持久化结果（仅内存 / 已写入 fe.conf（N 台）/ 部分写入）、状态（需要 `param.history`）。在 StarRocks 里直接执行 SQL 或登录机器改配置文件的修改不会出现在这里。

## 6. 常用参数速查

| 参数 | 类型 | 说明 |
|---|---|---|
| `qe_slow_log_ms` | FE | 慢查询阈值 |
| `default_replication_num` | FE | 建表默认副本数 |
| `max_running_txn_num_per_db` | FE | 单库运行中导入事务上限 |
| `tablet_sched_max_scheduling_tablets` | FE | 副本修复 / 均衡并发 |
| `enable_sql_blacklist` | FE | 是否启用 SQL 黑名单 |
| `cumulative_compaction_num_threads_per_disk` | BE | 每盘 Compaction 线程 |
| `storage_flood_stage_usage_percent` | BE | 磁盘超过该比例拒绝导入 |
| `mem_limit` | BE（静态） | BE 进程内存上限 |
| `query_timeout` | 变量 | 查询超时（秒） |
| `query_mem_limit` | 变量 | 单查询单 BE 内存上限 |
| `enable_spill` | 变量 | 中间结果落盘 |

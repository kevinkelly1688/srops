# 快速入门

StarRocks 运维平台（下称“平台”）面向 DBA 与运维工程师，覆盖 StarRocks 集群从**安装部署**、**日常巡检**、**性能诊断**到**扩缩容 / 升级 / 备份**的全生命周期管理，并提供精确到**功能按钮**的权限控制与完整的操作审计。

> 本手册中的概念、命令与参数均以 StarRocks 官方中文文档为准：[docs.mirrorship.cn](https://docs.mirrorship.cn/zh/docs/introduction/StarRocks_intro/)。平台当前为原型版本，页面数据为模拟数据。

## 1. 登录与界面

打开平台先进入登录页，使用平台账号和密码登录，详见 [登录、账号与主题](#help/login)。登录后界面如下：

| 区域 | 说明 |
|---|---|
| 左侧菜单 | 按「概览 / 性能与诊断 / 集群运维 / 告警与审计 / 平台配置 / 帮助」分组。**只显示你有「查看」权限的菜单**。 |
| 顶栏 · 集群切换 | 选择要操作的集群。没有数据范围权限的集群显示为 🔒 且不可选。 |
| 顶栏 · ? 帮助 | 打开当前页面对应的手册章节。 |
| 顶栏 · 主题 | 浅色 / 深色 / 🌿 护眼 三种主题，记在本机浏览器，见 [登录、账号与主题](#help/login)。 |
| 顶栏 · 头像 | 个人菜单：个人信息与权限、修改密码、主题、退出登录。旁边的下拉框为原型演示用，可不退出直接**切换身份**，对比不同角色看到的菜单和按钮。 |
| 页面水印 | 登录后页面带有包含你姓名 / 账号的半透明水印，用于截图外泄追溯，由超级管理员统一配置。 |
| 右侧抽屉 | 节点详情、Query Profile、日志等详情内容在右侧抽屉展示，按 `Esc` 关闭。 |

## 2. 按钮的三种状态

平台的每一个操作按钮都绑定一个**权限码**（例如 `node.decommission`）：

- **正常**：你拥有该权限码，可以点击。
- **置灰 + 🔒**：你没有该权限码。鼠标悬停可看到需要的权限名称和权限码，可据此向管理员申请。（管理员可在「平台设置 → 安全策略」改为直接隐藏。）
- **红色边框**：高危操作。执行前需要**输入集群名确认**；若开启了**双人复核**，提交后需另一人批准才会执行。

所有按钮操作——包括因无权限被拒绝的尝试——都会写入「操作审计」。

## 3. 两种集群架构

| 架构 | 组件 | 数据位置 | 平台差异 |
|---|---|---|---|
| 存算一体（shared-nothing） | FE + BE（可选 CN） | BE 本地盘，Tablet 多副本 | 节点管理有 BE 页签；巡检包含磁盘、副本、Compaction |
| 存算分离（shared-data） | FE + CN + 对象存储 | S3 / HDFS / OSS 等，CN 本地盘作为 Data Cache | 无 BE；关注缓存命中率与对象存储 |

- **FE（Frontend）**：元数据管理、查询规划、接入客户端。角色有 Leader / Follower / Observer。生产建议 3 个 Follower（含 Leader，奇数）。
- **BE（Backend）**：数据存储 + 查询执行。
- **CN（Compute Node）**：无状态计算节点，可快速扩缩容。

## 5. 第一次使用的推荐顺序

1. 平台独立部署后为空。管理员在「平台配置 → 集群接入」**导入已有集群**，并填写必填信息（FE 连接、SSH 与部署目录）后才能运维；也可在「安装部署」新建集群。详见 [平台部署与集群导入](#help/install)。
2. 在「角色权限」检查预置角色是否符合团队分工，按需新建角色；在「用户管理」创建账号并分配角色。
3. 在「告警中心 → 通知渠道」配置值班群（飞书 / Lark / Slack 等）；在「平台设置」确认安全策略与水印内容；在「性能巡检 → 定时与规则」开启每日巡检。
4. 运行一次「立即巡检」，按「异常 → 警告 → 建议」的顺序处理问题。

## 6. 术语

| 术语 | 含义 |
|---|---|
| Tablet | 表数据按分区、分桶切分后的最小存储与调度单元，每个 Tablet 有多个副本 |
| Compaction | 合并导入产生的数据版本；Score 越高说明待合并越多，查询越慢 |
| Routine Load | 持续消费 Kafka 的导入作业 |
| 资源组 | 按用户 / 角色 / 来源等分类，限制查询的 CPU、内存与并发 |
| 黑名单（BE / CN） | 暂时不参与查询调度的节点 |
| DECOMMISSION | 安全下线：先迁移副本再移除节点 |
| 权限码 | 平台中每个按钮的唯一标识，如 `backup.restore` |
| 数据范围 | 角色可以操作的集群列表 |

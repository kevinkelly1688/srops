# 集群接入 / 平台设置

## 集群接入

平台通过三种通道管理集群：

| 通道 | 用途 |
|---|---|
| MySQL 协议（FE 9030） | 执行 SQL：SHOW / ALTER SYSTEM / ADMIN SET / BACKUP 等 |
| HTTP（FE 8030、BE 8040） | 读取 `/metrics`、修改 BE 配置、查看日志 |
| SSH | 启停进程、部署、主机检查 |

### 导入集群

**＋ 导入集群**（`cluster.add`）打开 5 步导入向导：基本信息 → FE 连接（必填，测试通过）→ SSH 与部署目录（运维必填，可稍后填写）→ 监控与审计（可选）→ 确认导入。详见 [平台部署与集群导入](#help/install)。

### 集群列表

| 列 | 说明 |
|---|---|
| 必填信息 | **完整 · 可运维**，或 **待完善**（列出缺少的 SSH 凭据 / 部署目录，集群只读） |
| 可选信息 | Prometheus、审计表是否已配置 |

### 操作

| 按钮 | 权限码 | 说明 |
|---|---|---|
| 完善信息 | `cluster.edit` | 仅“待完善”集群显示，直接进入向导第 3 步补全 SSH 与部署目录 |
| 测试 | `cluster.test` | 逐项测试 MySQL、HTTP、权限、Prometheus、SSH |
| 编辑 | `cluster.edit` | 用同一向导修改连接、SSH、监控等信息（名称不可改） |
| 移除（高危） | `cluster.delete` | 只解除纳管，**不会**停止或删除 StarRocks 集群 |

## 平台设置

### 安全策略（`setting.security`）

连接平台服务时，以下设置**保存在服务端并立即生效**：

| 设置 | 说明 | 范围 |
|---|---|---|
| 无权限按钮显示方式 | **置灰并显示 🔒**（推荐，用户知道缺什么权限）或 **隐藏**；所有用户的页面都按此显示 | — |
| 高危操作二次确认 | 执行前输入目标名称（集群名 / 用户账号 / 角色名）；这是界面确认，用于防误操作 | — |
| 高危操作双人复核 | 开启后，高危操作需另一人批准才执行，**由服务端强制**，不是界面行为。见 [操作审计 → 待复核](#help/alert) | — |
| 会话超时 | 无操作超过该时间，会话失效需重新登录（另有 12 小时绝对上限） | 5–480 分钟 |
| 密码最小长度 | 创建用户、重置密码、修改密码时校验（同时要求大小写字母、数字和符号）；随机密码长度也会随之增加 | 8–32 位 |
| 密码过期天数 | 超过天数后，用户下次登录必须修改密码；0 = 永不过期。升级前创建的账号从首次登录起计算 | 0–3650 |
| 登录失败锁定 | 连续输错 N 次密码，账号临时锁定 30 分钟（管理员可在「用户管理」解锁） | 3–20 次 |
| IP 白名单 | 逗号分隔的 IP 或 CIDR（如 `10.0.0.0/8, 192.168.1.5`）；不在名单内的来源访问平台任何页面 / 接口都会被拒绝，留空 = 不限制 | — |

**IP 白名单的安全设计：**

- 保存时，您**当前的来源 IP 必须在新白名单内**，否则拒绝保存，避免把自己锁在门外。
- **本机（127.0.0.1 / ::1）始终可访问**，是误锁后的恢复途径：登录服务器本机，通过本机访问平台修改白名单即可。
- 平台部署在反向代理（Nginx 等）后面时，需在服务启动参数中加 `-trusted-proxies <代理地址>`（见 [平台部署与集群导入](#help/install)），平台才会从 `X-Forwarded-For` 中取真实来源 IP（取最靠右的不可信地址，客户端伪造的头无效）。**未配置时来源 IP 是代理的地址**，白名单与审计中的“来源 IP”都会是代理地址。

### 通知（`setting.notify`）

配置**邮件服务（SMTP）**、**短信网关**与告警的**发送策略**。

| 分组 | 设置 | 说明 |
|---|---|---|
| 邮件服务（SMTP） | 邮件服务器 / 端口 / 加密 | SSL/TLS（常用 465）、STARTTLS（常用 587）或不加密（25） |
| | 不校验服务器证书 | 仅用于使用自签名证书的内网邮件服务器；公网服务请勿勾选 |
| | 认证账号 / 密码 | 留空为匿名发送；密码**加密保存**，已设置时留空表示保持不变，清空账号会同时清除密码。很多邮箱需使用“授权码”而不是登录密码 |
| | 发件人地址 / 名称 | 必须是 SMTP 账号允许代发的地址 |
| | 发送测试邮件 | **真实发送**：用表单中当前填写的（尚未保存的）配置，发到当前登录用户的邮箱，保存前即可验证 |
| 短信网关 | 服务商（阿里云 / 腾讯云 / 通用 HTTP 网关）、接入点、AccessKey、签名、模板、模板变量 | 供告警中心的「短信」通知渠道使用，密钥加密保存；可先**发送测试短信**（详见「告警中心」→ 短信渠道） |
| 发送策略 | 告警合并 / 重复提醒 / 恢复通知 / 免打扰时段 | 已保存，**告警中心接入后生效** |

邮件服务（SMTP）目前用于：① 定时巡检结果通知，通知方式选「邮件」；② 创建 / 重置用户时勾选“同时发送到用户邮箱”（邮件以明文传输密码，仅建议在内部可信的邮件服务上使用，用户首次登录仍须修改密码）。

### 水印（仅超级管理员可自定义）

登录后的所有页面（包括弹窗、抽屉，以及打印 / 导出的 PDF）都会铺满半透明水印，用于截图、拍屏外泄时追溯到人。登录页不显示水印。

- **只有拥有「超级管理员」角色的用户**能点击 **自定义**；其他用户在此页只能查看当前配置和效果（按钮显示 🔒）。
- 可配置：开启 / 关闭、两行文字、字号、透明度、旋转角度、间距、颜色，提供「标准 / 醒目 / 轻量」预设，右侧实时预览。
- 文字支持变量，按每个登录用户分别替换：

| 变量 | 含义 |
|---|---|
| `{name}` / `{login}` | 姓名 / 账号 |
| `{dept}` | 部门 |
| `{phone4}` | 手机号后四位 |
| `{ip}` | 来源 IP |
| `{date}` / `{time}` | 当前日期 / 时间（每分钟刷新） |
| `{cluster}` | 当前选中的集群 |

- 修改后立即对全部用户生效，并记录到「操作审计」（权限码 `setting.watermark`）。
- 水印被浏览器开发者工具删除或隐藏时会自动恢复。

### 基础（`setting.basic`）

| 设置 | 说明 |
|---|---|
| 平台名称 | 显示在浏览器标签页与顶栏，最多 30 个字 |
| 平台访问地址 | 用户实际访问平台的地址（使用反向代理时填代理后的地址）。定时巡检通知与测试消息中的“查看详情”链接、用户账号邮件中的登录地址使用它 |
| 出网 HTTP 代理 / 不走代理的地址 | Lark、Slack 等境外通知渠道需要；格式 `http://主机:端口`（可带 `用户:密码@`，密码在页面上显示为 `****`，编辑时保持 `****` 即沿用原密码）。“不走代理”支持主机名、域名后缀（`*.example.com`）与 CIDR。未配置时回退到服务进程的 `HTTPS_PROXY` 环境变量 |
| 指标采集间隔 | 15 / 30 / 60 秒；用于未配置 Prometheus 时平台内置的趋势采样，下一轮采样起生效 |
| 巡检报告保留 | 7 – 730 天，超过的报告在读取时不再显示 |
| 审计日志保留 | 不少于 180 天，保留期内不可删除，超过的自动清理 |
